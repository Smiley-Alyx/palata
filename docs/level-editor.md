# Редактор карт PALATA

Редактор карт предназначен для локальной разработки уровней. Он позволяет менять геометрию,
материалы стен, точку появления игрока, сущности, освещение и звуковые триггеры, а затем
сохранять результат непосредственно в JSON-файл уровня.

Редактор работает только через локальный dev-сервер. На GitHub Pages сохранение и запуск
редактора отключены.

## Запуск редактора

1. Установить зависимости, если они ещё не установлены:

   ```bash
   npm install
   ```

2. Запустить локальный сервер:

   ```bash
   npm run dev
   ```

3. Открыть выведенный Vite адрес, обычно `http://localhost:5173/`.
4. Открыть консоль разработчика браузера.
5. Выполнить одну из команд:

   ```js
   palata.editor('level1'); // открыть level1.json
   palata.editor('level3'); // открыть level3.json
   palata.editor(2); // открыть level2.json
   palata.editor('/assets/data/levels/level4.json'); // открыть по полному пути
   palata.editor(); // создать новую пустую карту level.json
   ```

Новая пустая карта сохраняется как `public/assets/data/levels/level.json`. Чтобы использовать
для неё `Playtest`, карту необходимо добавить в `public/assets/data/levels/index.json`.

## Основные области интерфейса

### Верхняя панель

| Кнопка       | Назначение                                              |
| ------------ | ------------------------------------------------------- |
| `Undo`       | Отменить последнее изменение.                           |
| `Redo`       | Повторить отменённое изменение.                         |
| `View`       | Открыть выбранную текстуру или спрайт на весь экран.    |
| `Playtest`   | Сохранить карту и сразу запустить уровень для проверки. |
| `Save level` | Сохранить изменения в JSON-файл уровня.                 |
| `Close`      | Закрыть редактор без дополнительного сохранения.        |

Звёздочка перед названием уровня означает, что в редакторе есть несохранённые изменения.

### Левая панель

В блоке `Current tool` всегда показаны:

- активный инструмент;
- выбранная кисть, сущность или материал;
- действие, которое произойдёт при клике по карте.

Ниже находятся инструменты, информация о размере карты, настройка размера, масштаб и краткая
справка по клавишам.

### Центральная область

Центральная область содержит сетку карты. Клик выбирает клетку и применяет активный инструмент.
Для рисования геометрии, материалов и удаления можно зажать кнопку мыши и провести по клеткам.
Кнопка `Select all cells` или сочетание `Ctrl/Cmd+A` выделяет всю карту для массового изменения
геометрии, материала или очистки через инспектор.

Маркеры клетки:

- `S` — точка появления игрока;
- `M` — material override;
- число в правом верхнем углу — количество сущностей;
- `L` — источник света;
- `T` — звуковой триггер.

При задержке курсора над клеткой отображаются координаты, значение геометрии, фактический
материал и количество объектов.

### Правая панель

Правая панель содержит:

- `Selection` — содержимое и редактирование выбранной клетки;
- `Materials` — материалы стен;
- `Entities` — сущности, разбитые по категориям;
- `New note text` — необязательные заголовок и текст для новой выбранной записки;
- `Light` — параметры нового источника света;
- `Sound Trigger` — параметры нового звукового триггера.

При задержке курсора над инструментом, материалом, категорией или сущностью отображается
пояснение.

## Инструменты

| Инструмент      | Клавиша | Назначение                                                |
| --------------- | ------- | --------------------------------------------------------- |
| `Spawn`         | `S`     | Переместить точку появления игрока в центр клетки.        |
| `Material`      | `M`     | Нарисовать выбранный material override.                   |
| `Entity`        | `E`     | Разместить выбранную сущность в центре клетки.            |
| `Light`         | `L`     | Разместить источник света с параметрами из правой панели. |
| `Sound zone`    | `T`     | Создать одноклеточный звуковой триггер.                   |
| `Erase object`  | `X`     | Удалить материалы, сущности, свет и триггеры из клетки.   |
| `Fill area`     | `F`     | Залить связанную область выбранным значением геометрии.   |
| `Inspect`       | `I`     | Выбрать клетку без размещения новых объектов.             |
| Геометрия `0–9` | `0–9`   | Выбрать значение геометрии и рисовать им по карте.        |

`Erase object` не меняет значение геометрии клетки. Для удаления стены выберите `0 Empty`.

## Значения геометрии

| Значение | Название      | Типичное назначение                             |
| -------- | ------------- | ----------------------------------------------- |
| `0`      | `Empty`       | Проходимое пустое пространство.                 |
| `1`      | `Wall`        | Основная сплошная стена.                        |
| `2`      | `Alt wall`    | Дополнительный слот стены, зависит от `legend`. |
| `3`      | `Window`      | Окно.                                           |
| `4`      | `Stand A`     | Дополнительный слот `legend`.                   |
| `5`      | `Stand B`     | Дополнительный слот `legend`.                   |
| `6`      | `Door`        | Дверь.                                          |
| `7`      | `Exit / gate` | Выход или дополнительный слот `legend`.         |
| `8`      | `Stand C`     | Дополнительный слот `legend`.                   |
| `9`      | `Stand D`     | Дополнительный слот `legend`.                   |

Фактическое назначение цифры определяется объектом `legend` в JSON уровня. Например, `1: wall`
по умолчанию отображается как `medical_tiles`, а `6: door` — как `medical_door`.

## Выбор и изменение существующих объектов

Выберите инструмент `Inspect` и кликните по клетке. Редактор определит фактический материал,
сущности и остальные объекты этой клетки.

В блоке `Edit selected cell` доступны:

- `Geometry` — изменить тип клетки;
- `Material` — выбрать material override или вернуть значение `Default` из `legend`;
- `Entity N` — заменить размещённую сущность другой сущностью из палитры;
- `Sprite N` — изменить конкретный спрайт сущности, если она хранит поле `sprite`.
- `Title N` и `Text N` — изменить собственную надпись выбранной записки;
- `Delete everything from cell` — сделать клетку пустой и удалить из неё материалы и объекты.

При выделении всей карты блок меняется на `Edit selected cells`. Изменения `Geometry`,
`Material` и удаление применяются ко всем выделенным клеткам.

Если удаляемая клетка содержит точку появления игрока, редактор переносит её на другую пустую
клетку, когда это возможно.

При выборе клетки инструментом `Inspect` палитры материалов и сущностей синхронизируются с её
содержимым. В информации о материале отображаются:

- `effective` — материал, который реально используется;
- `override` — явное переопределение из `materialsWall`;
- `legend` — семантическое значение геометрии уровня.

Все изменения через инспектор поддерживают `Undo` и `Redo`.

## Материалы

Чтобы нарисовать материал:

1. Выберите материал в разделе `Materials`.
2. Убедитесь, что в `Current tool` указан режим `Paint material`.
3. Зажмите ЛКМ и проведите мышью по нужным клеткам. Выбранный материал останется активным на
   протяжении всего мазка.

Материал создаёт запись в `materialsWall`. Он переопределяет текстуру клетки, но не меняет её
геометрию и проходимость.

Чтобы вернуть стандартный материал из `legend`, выберите клетку через `Inspect` и установите
`Material` в `Default`.

## Сущности

Сущности разбиты по категориям:

- `Documents` — сюжетные предметы, текст которых берётся из соответствующего `messagePools`;
- `Keys` — ключи и замки;
- `Pickups` — здоровье, лекарства, патроны, артефакты и броня;
- `Weapons` — подбираемое оружие;
- `Enemies` — точки появления врагов;
- `Audio` — позиционные зацикленные звуки;
- `Props` — декоративные объекты.

Для сущностей из категории `Documents` можно заполнить блок `New note text` перед размещением.
Такая записка хранит собственные поля `title` и `text` и показывает их вместо случайного
сообщения из `messagePools`. Если оба поля оставить пустыми, записка продолжает использовать
соответствующий пул сообщений.

Чтобы разместить сущность:

1. Выберите её в разделе `Entities`.
2. Проверьте выбранную сущность в блоке `Current tool`.
3. Кликните по нужной клетке.

В одной клетке может находиться несколько сущностей. Для замены или изменения их спрайтов
используйте `Inspect` и поля `Entity N` / `Sprite N`.

## Свет

В разделе `Light` задаются:

- `Radius` — радиус освещения;
- `Intensity` — интенсивность;
- `Color` — цвет;
- `Mode` — режим работы: `steady`, `flicker`, `emergency`, `pulse` или `organic`.

Изменение любого параметра автоматически выбирает инструмент `Light`. После настройки кликните
по клетке, чтобы разместить источник.

## Звуковые триггеры

В разделе `Sound Trigger` задаются:

- `Sound` — воспроизводимый звук;
- `Volume` — громкость;
- `Once` — должен ли триггер сработать только один раз.

После настройки кликните по клетке. Редактор создаст `enter_zone` размером одну клетку с
действием `play_sound`.

## Просмотр текстур и спрайтов

Кнопка `View` становится доступной после выбора:

- материала;
- сущности со спрайтом;
- клетки с материалом или сущностью.

В полноэкранном режиме отображаются название, логический ID и путь ассета. Если файл содержит
несколько описанных спрайтов или кадров, доступны:

- список кадров;
- кнопки `Previous` и `Next`;
- переключение стрелками влево и вправо.

Просмотр закрывается кнопкой `Close`, клавишей `Escape` или кликом по затемнённому фону.

Редактор использует точные координаты из `public/assets/animations/*.json`. Если для файла нет
описания кадров, отображается полное изображение.

## Размер карты и масштаб

В блоке `Map size` задаются ширина и высота от `3` до `128` клеток. Кнопка `Resize` изменяет
размер по правому и нижнему краям:

- существующие клетки в левом верхнем углу сохраняются;
- новые клетки заполняются значением `0`;
- объекты за новыми границами удаляются;
- точка появления игрока перемещается внутрь карты, если оказалась за границей.

Изменение размера можно отменить через `Undo`.

Масштаб сетки меняется кнопками `-` / `+`, ползунком или клавишами `-` / `+`.

## Сохранение и проверка уровня

`Save level` или `Ctrl/Cmd+S` перезаписывает JSON-файл в
`public/assets/data/levels/`. Сохранение выполняет локальный Vite-плагин и доступно только при
запуске через `npm run dev`.

`Playtest` выполняет следующие действия:

1. Сохраняет текущие изменения.
2. Загружает свежую версию уровня без кеша.
3. Запускает игровой режим.
4. Показывает кнопку `Back to editor`.

`Back to editor` останавливает игровой режим и заново открывает сохранённый файл карты.

Для `Playtest` уровень должен быть зарегистрирован в `public/assets/data/levels/index.json`.

## Горячие клавиши

| Клавиши                          | Действие                              |
| -------------------------------- | ------------------------------------- |
| `0–9`                            | Выбрать значение геометрии.           |
| `S`                              | Выбрать `Spawn`.                      |
| `M`                              | Выбрать `Material`.                   |
| `E`                              | Выбрать `Entity`.                     |
| `L`                              | Выбрать `Light`.                      |
| `T`                              | Выбрать `Sound zone`.                 |
| `X`                              | Выбрать `Erase object`.               |
| `F`                              | Выбрать `Fill area`.                  |
| `I`                              | Выбрать `Inspect`.                    |
| `+` / `-`                        | Изменить масштаб сетки.               |
| `Ctrl/Cmd+S`                     | Сохранить уровень.                    |
| `Ctrl/Cmd+Z`                     | Отменить изменение.                   |
| `Ctrl/Cmd+Shift+Z`, `Ctrl/Cmd+Y` | Повторить отменённое изменение.       |
| `Escape`                         | Закрыть просмотр ассета или редактор. |
| `←` / `→`                        | Переключить кадр в просмотре ассета.  |

Горячие клавиши инструментов не перехватываются, пока курсор находится в поле ввода или списке.

## Рекомендуемый рабочий процесс

1. Запустить `npm run dev`.
2. Открыть нужный уровень через `palata.editor("levelN")`.
3. Использовать `Inspect`, чтобы проверить существующее содержимое карты.
4. Внести изменения.
5. Периодически нажимать `Save level`.
6. Использовать `Playtest` и `Back to editor` для быстрой проверки.
7. Проверить изменённые JSON-файлы через `git diff`.
8. Запустить проверки:

   ```bash
   npm run typecheck
   npm run lint
   npm run build
   ```

9. Вручную добавить нужные файлы карты в коммит.

## Важные ограничения

- Редактор не работает на GitHub Pages.
- `Close` и `Escape` не сохраняют изменения автоматически.
- `Playtest` работает только для уровней из `index.json`.
- Уменьшение карты удаляет объекты за новыми границами.
- `Erase object` удаляет все материалы и объекты клетки, но не геометрию.
- Замена типа сущности сохраняет её ID и условия включения, но остальные специфичные поля
  заменяются настройками новой сущности.
- Полноэкранный просмотр может выбирать только кадры, описанные в файлах анимаций. Для остальных
  ассетов показывается полное изображение.
